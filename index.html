Aperture 是一套为数据密集型界面打造的暗色优先设计语言。它把色彩收敛为单一强调色， 把层级交给亮度阶梯，把结构交给半透明的白色描边 —— 让每一个像素都为信息服务。

01 — Overview

理念与使用方式

Aperture 的每一层设计都建立在一个判断上：开发者界面需要的是秩序，而非装饰。 因此系统只提供一条路径去表达层级 —— 通过背景亮度的细微阶梯，而不是阴影、渐变或色彩。

亮度即层级

暗色表面上，阴影几乎不可见。层级改由背景白度表达：0.2% → 4% → 5%，每一级都更"亮"一点。

描边而非边框

用零偏移的 box-shadow 代替 CSS border，让描边活在阴影层里，转角不会被裁切，过渡也更顺滑。

单一强调色

紫色是系统里唯一的彩色。它只出现在 CTA、激活态与焦点环上 —— 一旦用于装饰，秩序就崩塌了。

四条核心原则

  • P1
    收敛色彩

    整体保持无彩，只在需要引导动作时注入强调色。饱和度控制在 70% 以下，避免噪点感。

  • P2
    字号驱动层级

    字重只有三档：400 用于阅读、510 用于导航与标签、590 用于宣告。层级靠字号与字距拉开。

  • P3
    负字距压缩

    大字号越紧越好 —— 36px 用 -0.042em，13px 起回归常规。压缩带来"被工程化"的精密感。

  • P4
    4px 网格节奏

    所有间距都是 4 的倍数。任何偏移 4px 的数值都需要有光学对齐的理由。

如何接入

快速开始 3 steps
tokens.css 
/* 1. 引入令牌层 —— 所有设计决策的唯一入口 */
@import "./aperture/tokens.css";

/* 2. 应用基础层 —— 重置与字体特性 */
@import "./aperture/base.css";

/* 3. 按需引入组件 —— 未使用的组件不会进入产物 */
@import "./aperture/components/button.css";
@import "./aperture/components/input.css";

提示：永远不要在业务代码里写死色值。所有颜色、间距、圆角都必须引用令牌变量 —— 这是系统可维护的前提。

Spacing 间距系统

一切间距都基于 4px 网格。克制的间距刻度比丰富的刻度更容易建立节奏 —— 选项越少，一致性越高。

4px 基准网格

使用代码片段

spacing.css 
/* 推荐：用语义化的间距变量描述意图 */
.stack {
  display: flex;
  flex-direction: column;
  gap: var(--space-4);        /* 16px — 块内元素 */
}

.section {
  padding-block: var(--space-20);  /* 80px — 区块间留白 */
}

/* 反例：魔术数字会破坏节奏 */
.bad { padding: 13px 27px; }

Toast 轻提示

Feedback global · auto-dismiss
规则：视口底部居中浮现，1.9s 自动消失；通过 aria-live="polite" 播报给读屏器；只承载轻量反馈，不放置操作按钮，关键确认一律交给 Modal。
Toast JS
toast.js 
// 唯一的轻提示入口：改文案、显示、重置计时器
function showToast(msg) {
  toastMsg.textContent = msg;
  toast.classList.add('show');
  clearTimeout(toastTimer);
  toastTimer = setTimeout(() => toast.classList.remove('show'), 1900);
}
